# Traffic Capture and Nmap Scan Analysis

## Objective

The objective of this task was to capture network traffic generated by an Nmap SYN scan and analyze the captured packets using Tcpdump and Wireshark.

## Lab Environment

- Network: 192.168.56.0/24
- Monitoring Interface: eth1
- Analyst Machine: Kali Linux (192.168.56.101)
- Target: Metasploitable2 (192.168.56.102)
- Tools: Tcpdump, Wireshark, Nmap

## Methodology

Tcpdump was used to capture network traffic on the Host-Only interface while an Nmap SYN scan was performed against the Metasploitable2 target.

The captured traffic was then opened and analyzed in Wireshark. A display filter was applied to identify TCP SYN packets that did not contain the ACK flag. This filtering technique was used to identify the traffic pattern associated with the Nmap SYN scan.

## Results

The traffic capture successfully recorded network packets generated during the Nmap SYN scan. Wireshark analysis identified TCP SYN packets without the ACK flag, allowing the Nmap scanning activity to be distinguished from normal established TCP connections.
