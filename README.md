# Network Threat Monitoring Lab

## Overview
A cybersecurity network monitoring lab built in an isolated VirtualBox environment to analyze network traffic, identify hosts, and monitor security events.

## Lab Environment
- Platform: Oracle VirtualBox
- Network: 192.168.56.0/24 Host-Only Network

## Systems Used
- Kali Linux (Analyst Machine)
- Metasploitable2 (Target Machine)
- DVWA (Web Application)

## Tools Used
- Nmap
- Wireshark
- TShark
- tcpdump
- Zeek
- ntopng
- Docker

## Activities Completed
- Network discovery and host scanning
- Packet capture and analysis
- TCP SYN scan analysis
- Web traffic monitoring
- Security event monitoring

## Skills Demonstrated
- Network security monitoring
- Packet analysis
- Linux security tools
- Vulnerability assessment
- Cybersecurity documentation
