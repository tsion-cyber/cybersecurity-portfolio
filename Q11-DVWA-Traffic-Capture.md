# DVWA Traffic Capture

## Objective

The objective of this task was to stand up the Damn Vulnerable Web Application (DVWA) and capture network traffic while logging in and browsing the application and vulnerability pages.

## Lab Environment

- Network: 192.168.56.0/24
- Analyst Machine: Kali Linux (192.168.56.101)
- DVWA: Docker web application
- Tool: tcpdump
- Packet Capture File: `dvwa_capture.pcap`

## Traffic Capture Procedure

DVWA was started using Docker and accessed through a web browser. The analyst logged into the DVWA web application and browsed the application and vulnerability pages. During this activity, `tcpdump` was used to capture the network traffic generated by the web application activity.

The captured network traffic was saved as `dvwa_capture.pcap` for further analysis using Wireshark.
