# Wireshark Display Filters

## Objective

The objective of this task was to use Wireshark display filters to isolate specific network traffic for analysis, including host communication, HTTP traffic, and TCP SYN scan activity.

## Lab Environment

- Network: 192.168.56.0/24
- Analyst Machine: Kali Linux (192.168.56.101)
- Target Machine: Metasploitable2 (192.168.56.102)
- Tool: Wireshark

## Display Filters Used

### 1. Host Traffic

```text
ip.addr == 192.168.56.102
```

This filter displays all traffic to and from the Metasploitable2 host.

### 2. HTTP Traffic

```text
http
```

This filter displays only HTTP packets captured during the lab.

### 3. TCP SYN Scan Traffic

```text
tcp.flags.syn == 1 && tcp.flags.ack == 0
```

This filter isolates TCP SYN packets without the ACK flag, making it useful for identifying Nmap SYN scan activity.

## Results

The display filters successfully isolated different categories of network traffic. Filtering by host IP showed all communication with the Metasploitable2 system, the HTTP filter displayed web traffic, and the TCP SYN filter highlighted reconnaissance traffic generated by the Nmap SYN scan.
